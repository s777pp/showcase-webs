КАК ВЫЛОЖИТЬ РУКОВОДСТВО В STEAM

Папки:
  ru/guide.txt + ru/images/   — русское руководство
  en/guide.txt + en/images/   — английское руководство (отдельное руководство, тот же порядок действий)

1. Создать руководство
   Откройте https://steamcommunity.com/sharedfiles/editguide/?appid=753 (руководство в хабе «Steam»).
   Если ссылка не откроется: Сообщество → Хабы → найдите «Steam» → «Руководства» → «Создать руководство».

2. Заполнить шапку (берите из guide.txt)
   - Название — блок «НАЗВАНИЕ» / «TITLE».
   - Описание — блок «ОПИСАНИЕ» / «DESCRIPTION».
   - Картинка-превью — images/01-cover.png.
   - Язык — русский (для ru) / английский (для en). Категория — та, что ближе к профилю/оформлению.
   - Отметьте согласие с условиями и сохраните. Руководство создаётся скрытым, его видно только вам.

3. Загрузить все картинки
   В редакторе руководства откройте «Изображения» и загрузите сразу все файлы из images/ (кроме 01-cover.png).
   Все файлы меньше 2 МБ. Steam принимает JPG, PNG и GIF.

4. Добавить разделы по порядку
   Для каждого блока «РАЗДЕЛ N — …» / «SECTION N — …»:
   - «Добавить раздел»;
   - заголовок раздела — текст после тире;
   - содержимое — весь текст блока (BBCode уже правильный: [b], [list], [table], [code], [url]);
   - там, где стоит строка [[КАРТИНКА: имя]] / [[IMAGE: name]], поставьте курсор и нажмите у нужной картинки
     «Добавить в раздел» (Steam вставит [previewimg=...]); строку-метку удалите;
   - сохраните раздел.

5. Проверить и опубликовать
   «Предпросмотр» → если всё на месте, в настройках видимости поставьте «Публичное» и сохраните.
   Через пару минут руководство появится в хабе. Первые лайки и избранное от знакомых помогают ему подняться.

Пересобрать картинки после изменений сайта:
   py -3.14 main.py   (локальный сервер)  →  py -3.14 scripts/build_steam_guide.py
