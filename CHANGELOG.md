### Создать дизайн (Builder) — новая студия
- Новый понятный макет: слева панель инструментов (Фон, Персонаж, Текст, Рамка, Эффекты | Шаблоны, Длина сцены),
  рядом панель настроек выбранного инструмента, в центре холст с верхней панелью (отменить/повторить, настройки
  холста, «Выбранный фон» + кнопка покупки), справа слои.
- Слои: переименование прямо в списке (двойной клик, F2 или карандаш), перетаскивание мышью или за ручку на
  телефоне, Alt + ↑/↓ с клавиатуры. Поле «Название» убрано.
- Каталог фонов Steam открывается на большом холсте, карточки не сжимаются при подгрузке.
- **Анимированные фоны Steam грузятся в разы быстрее**: браузер берёт видео прямо с CDN Steam (раньше сервер
  сначала целиком скачивал файл и только потом отдавал его; в тесте 15 с → 1,4 с). Серверный прокси остался
  запасным вариантом и теперь кэширует файлы на диске с докачкой по частям. Пока фон грузится, на холсте видно
  уведомление с процентами, а если грузится долго — объяснение, что это видео на несколько МБ и скорость зависит
  от интернета.
- Эффекты выбираются плитками с живым превью; новых эффектов 15 (аура, светлячки, боке, гиперпрыжок, сеть,
  кольца-эквалайзер, скан-импульс, магический круг, гекс-импульс, глитч, волна точек, дым, угольки, осколки,
  пиксельные кресты). Переделаны «Поток частиц» и «Звёздный поток» (раньше были одинаковыми), «Световые линии»
  стали «Кометами», дождь стал реалистичным (3 слоя глубины, брызги, дымка).
- Настройки элемента разложены по сворачиваемым группам (удаление фона, анимация, цветокоррекция, глубина и
  свет, положение), состояние запоминается.
- Размер и поворот персонажа/текста меняются ручками прямо на холсте.
- Библиотека шрифтов в отдельном окне: 1220 шрифтов Google Fonts с превью на слове «ShowcaseMaker», избранное,
  загрузка своего шрифта с компьютера (хранится в этом браузере).
- Текст: направление «Горизонтально / Вертикально» (буквы стоят ровно, идут сверху вниз).
- Анимации текста (17): печатная машинка, появление по буквам, расшифровка, волна, выпрыгивание, Saber, неон
  (полые буквы-трубки со свечением), глитч, радуга, блик и эффекты по контуру букв: огненная обводка (горящий
  контур, языки пламени, клубы и угольки), электричество (искрящие рваные разряды по краю букв), молнии (разряды
  между краями), бегущая обводка, переливы, блёстки. Цвет свечения и скорость (×1…×4 за цикл сцены). Анимации
  бесшовно зацикливаются в экспорте.
- Персонаж: «Подстроить под сцену» — анализ фона под персонажем и подбор яркости, контраста, насыщенности и
  оттенка (с силой и откатом к исходным цветам).
- Производительность: холст перерисовывается только при изменениях, анимированные сцены — не чаще 30 кадров/с;
  HUD-рамка с переливами 71 мс → ~4 мс на кадр. Ошибка в одном слое больше не останавливает редактор.
- «Длина сцены» вместо «Сцена».

### Рамки
- 12 новых рамок в стиле HUD (HUD, Колонны, Корона, Бастион, Две линии, Срезы, Крылья, Изгиб, Дуги, Техно,
  Схема, Клинки) + Классика/Скосы/Выемки, две новые анимации «Переливы» и «Зерно», тёмная подложка.
  Выбор картинками во всех местах: Обработка, Ряды и квадраты, Создать дизайн.
- Artwork Split: рамка рисуется одной на всю пару и режется, поэтому колонки в файлах 506 и 100 px одинаковой
  толщины (как у Featured) и зеркальны до пикселя, правая целиком помещается в 100 px.
- Когда дизайн из «Создать дизайн» переносится в «Обработку», рамки и цветокоррекция «Обработки» выключаются и
  блокируются (с пояснением и кнопкой «Всё равно добавить рамку»), чтобы поверх дизайна не легла вторая рамка.
  Если убрать этот файл из списка, прежний выбор возвращается.

## Как выложить (делает владелец)

### 1. В GitHub (`Desktop\showcase-webs`)
```powershell
cd C:\Users\n1t1337\Desktop\showcaseclaude
py -3.14 scripts/release_sync.py            # пробный прогон: список новых/изменённых файлов
py -3.14 scripts/release_sync.py --apply    # скопировать в showcase-webs (ничего не удаляет)
cd ..\showcase-webs
git status                                  # ожидается ~15 новых и ~64 изменённых файла
git add -A
git commit -m "Design studio: builder redesign, HUD frames, text animations, fast Steam backgrounds"
git push
```
`.env`, `data/`, `IMAGE/`, `output/`, `.claude/` не копируются. Переводы строк git нормализует сам (`.gitattributes`).

### 2. На VPS (`/opt/showcasemaker`)
```bash
cd /opt/showcasemaker
git rev-parse HEAD > ~/before-2026-09-30.txt                      # точка отката
docker compose exec -T postgres sh -c 'pg_dump -U "$POSTGRES_USER" -Fc "$POSTGRES_DB"' > ~/db-2026-09-30.dump
git pull --ff-only
docker compose config --quiet                                     # должно ничего не вывести
docker compose build --pull app worker                            # новые зависимости (pillow-heif) и Dockerfile
docker compose up -d
docker compose restart nginx                                      # nginx.conf смонтирован файлом: без рестарта останется старый
curl -fsS http://127.0.0.1:8080/api/ready && echo
docker compose exec -T app curl -fsS http://127.0.0.1:8080/api/health
docker compose logs --tail=80 app worker
python3 scripts/smoke_test.py https://showcasemaker.com
```
Ночной бэкап (`db-backup`) продолжает работать; ручной дамп — страховка именно на эту выкладку.

Необязательные строки в `.env` (без них работают значения по умолчанию):
`APP_MEM_LIMIT=3g`, `WORKER_MEM_LIMIT=6g`, `LOOP_PREVIEW_CONCURRENCY=1`.

### 3. Modal (отмена апскейла)
```powershell
py -m modal deploy modal_upscale.py
```
Без этого апскейл работает как раньше; отмена останавливает только сторону VPS.

### 4. После выкладки
- Открыть `/ru/app` → «Создать дизайн»: выбрать анимированный фон Steam, добавить текст с анимацией, перенести
  в «Обработку» и нарезать. Кэш браузера сбрасывать не нужно (ключи `?v=` обновлены).
- Новый кэш на диске: `/data/cache/steam-media` (не больше 600 файлов, старше 7 дней удаляются сами).

### Откат
```bash
git checkout "$(cat ~/before-2026-09-30.txt)" && docker compose build app worker && docker compose up -d && docker compose restart nginx
```
