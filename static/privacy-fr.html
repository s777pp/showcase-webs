Politique de confidentialité

01 Portée et contact

Cette politique couvre SteamShowcase Helper (l'extension du navigateur) et son intégration avec Showcase Maker sur showcasemaker.com. Développeur et exploitant : n1t1337 / Showcase Maker. Il s'agit d'un projet indépendant, pas d'un produit Valve.

Pour les demandes de confidentialité, d’accès ou de suppression, contactez le développeur via le profil n1t1337 Steam ou les options de contact d'assistance sur la chaîne Telegram officielle. Demandez à communiquer en privé ; ne publiez pas de mots de passe, de jetons ou de documents personnels dans les commentaires publics.

02 Ce que l'extension gère localement

  • Fichiers sélectionnés : images et animations, noms de fichiers, dimensions et paramètres de sortie pour le traitement et l'aperçu du moteur de navigateur local. Le traitement local ne télécharge pas le contenu du fichier vers Showcase Maker. Les résultats téléchargés restent sur votre appareil.
  • Préférences : langue, thème, outil actif, sélections d'aperçu, favoris et un instantané local du contenu de la page de profil utilisé pour restaurer l'aperçu.
  • Guide de téléchargement : type de vitrine, noms de fichiers, dimensions, ordre des éléments, étape actuelle et heure de début. Le site Web envoie ces métadonnées à l'extension ; vous sélectionnez toujours les fichiers vous-même dans Steam.
  • Onglets pertinents : Steam/URL des onglets du site et, si nécessaire, les titres et les identifiants des onglets pour ouvrir le bon outil ou rechercher un onglet de profil. L'extension ne maintient ni n'envoie de base de données générale d'historique de navigation, de journal de frappe ou de profil d'activité publicitaire.

Les paramètres utilisent le stockage des extensions de navigateur et localStorage. Les données d'aperçu peuvent également rester dans le stockage du site de Steam. La fermeture de la fenêtre contextuelle n'efface pas les paramètres persistants.

03 Demandes à Steam et informations d'identification

L'extension charge les arrière-plans, les avatars, les cadres et les données de catalogue de la communauté Steam, des API Steam et des domaines de diffusion de contenu Steam. Steam reçoit les URL demandées, votre adresse IP et les métadonnées normales du navigateur/réseau. Certaines requêtes Steam utilisent votre session Steam existante ; le catalogue peut lire le jeton d'API Web de fidélité exposé sur la page Steam et l'envoyer à l'API de Steam.

Les mots de passe Steam ne sont pas demandés par l'extension. Il n'exporte pas les cookies Steam ni ce jeton Steam vers Showcase Maker. L’importation de sites Web utilise à la place un ticket d’importation distinct de courte durée et à usage unique émis par Showcase Maker. N’envoyez jamais aucune de ces informations d’identification au support.

Lorsque vous choisissez un fichier à télécharger Steam, il est envoyé à Steam via le formulaire de téléchargement de Steam ; l'extension prépare les paramètres du formulaire et guide les étapes. La publication et la visibilité sont régies par les paramètres sur Steam, et non par l'aperçu local. Steam applique son propre politique de confidentialité.

04 Importer un profil sur le site Web

Lorsque vous lancez une importation basée sur une extension dans Showcase Maker, l'extension ouvre votre profil Steam et envoie un instantané structuré à Showcase Maker via HTTPS. Il peut inclure SteamID, l'URL du profil, le surnom, le nom réel affiché, le résumé, le statut, le niveau, les URL d'avatar/arrière-plan/cadre, les badges, les récompenses, les groupes, les compteurs, le texte de présentation, les liens et les URL des médias, les dimensions et le temps de capture. Seules les informations de profil exposées sur la page chargée peuvent être capturées ; n’y placez pas d’informations que vous ne souhaitez pas importer.

Le site valide le ticket d'importation, associe l'instantané à votre compte connecté et le stocke pour l'éditeur. Il peut enrichir l'instantané à l'aide des API Steam et télécharger/mettre en cache l'avatar, mettant ainsi à jour le nom d'affichage et l'avatar de votre site. Les informations de compte importées et les profils de site enregistrés ne sont pas des tâches de traitement jetables et n'expirent pas automatiquement après sept jours. Le nom d’affichage de votre site, votre avatar et tout profil public ou contenu de galerie peuvent être visibles par les autres visiteurs.

Le pont signale également la version de l'extension installée au site pris en charge et peut renvoyer les résultats du catalogue de personnalisation Steam. Localhost/127.0.0.1 est pris en charge uniquement pour le développement local ; une importation initiée localement est dirigée vers cette instance locale.

06 Services de site Web distincts

L'ouverture de Showcase Maker est différente de l'utilisation uniquement de l'extension locale. En fonction des fonctionnalités que vous choisissez, le site Web traite les identifiants de compte, les informations de courrier électronique et de connexion/session, les conceptions de profil enregistrées, les téléchargements, les résultats de travail, les publications de galerie, les commentaires, les likes, l'accès Pro et les références de transaction. Les fournisseurs de paiement et de connexion tiers gèrent leurs propres formulaires ; ne soumettez pas les détails de la carte de paiement dans le chat d’assistance. Le site Web utilise les cookies de session nécessaires, les paramètres/projets du navigateur et les compteurs anti-abus basés sur IP.

Les offres Pro achetées sur le site sont payées via Gumroad, qui gère le paiement et les données de carte ou PayPal. Le site ne reçoit de Gumroad que la référence d’achat, le produit, le prix et l’état de remboursement, les vérifie via l’API Gumroad et rattache l’achat à votre compte ; il ne reçoit jamais les données de carte.

Le Pro acheté via notre bot Telegram est payé dans Telegram (Stars, CryptoBot ou un paiement confirmé par le propriétaire). Le bot n’envoie au site que la référence du paiement, l’offre et votre identifiant Telegram ; le site associe cet identifiant au compte qui a reçu le Pro, pour que les achats suivants du même compte Telegram y arrivent aussi. Les données de carte n’atteignent jamais le site.

Les outils gratuits utilisables une fois par semaine comptent l’utilisation par compte et par une empreinte à clé de votre adresse IP (jamais l’adresse elle-même), afin qu’un second compte depuis le même réseau n’obtienne pas d’essais en plus. Ces compteurs sont supprimés après 60 jours.

OVH héberge l'application et la base de données ; Cloudflare fournit la connexion publique, la protection et, le cas échéant, le stockage multimédia R2. Les requêtes peuvent créer des journaux techniques contenant les adresses IP, les chemins demandés, les horodatages, l'état de la réponse et les métadonnées du navigateur. Ceux-ci prennent en charge le fonctionnement, la sécurité et le dépannage.

Analyse produit facultative : si vous choisissez « Autoriser », nous enregistrons les actions sur les pages et outils avec un identifiant aléatoire limité à la session du navigateur, la langue, la route, le type/la tranche de taille générale du fichier et le résultat du traitement. L’analyse ne stocke ni adresse IP, ni identifiant du navigateur, ni e-mail, ni Steam ID, ni nom de fichier, ni contenu média. Les événements opérationnels (inscription terminée, activation Pro, résultat du traitement et téléchargement ZIP) peuvent être enregistrés côté serveur. Les données détaillées sont supprimées au plus tard après 90 jours ; les totaux agrégés peuvent être conservés plus longtemps. Choisissez « Nécessaires seulement » pour refuser ou effacez les données du site pour choisir à nouveau.

Uniquement lorsque vous utilisez les fonctionnalités associées : fal.ai (modèle vidéo de MiniMax) reçoit l’image que vous envoyez à l’animation IA et votre souhait de mouvement, que Google Gemini peut d’abord reformuler en une courte consigne en anglais ; Modal (notre propre service GPU) traite les médias pour l'agrandissement par GPU et l'image fixe pour laquelle vous demandez explicitement la suppression du fond par IA ; vous pouvez aussi choisir un autre service, et si celui choisi est indisponible, l'image peut être envoyée à iLoveAPI, Problembo ou remove.bg ; Bright Data récupère les pages publiques Steam pour l'importation côté serveur ; Google Gemini reçoit une sélection de textes et d'images de profil public pour l'évaluation du profil/la sélection de conception ; Groq reçoit votre question d'assistance, une conversation récente limitée et des informations d'aide publique pour les réponses de l'IA. Cliquer sur une réponse FAQ intégrée n'invoque pas en soi Groq. Les messages de chat ne sont pas délibérément enregistrés en tant qu'enregistrements de conversation par notre application, mais les fournisseurs peuvent traiter ou conserver les données selon leurs propres politiques ; une option API n’est pas une garantie de rétention nulle. L'installation de l'extension à elle seule n'envoie pas vos fichiers à ces services d'IA.

Les liens externes (y compris Steam, DeviantArt, services de paiement et réseaux sociaux) ouvrent des services avec leurs propres règles de confidentialité. Certaines pages du site chargent les polices Google. Cette page de politique elle-même ne comprend aucune analyse, widget de chat ou demande de police externe.

07 Conservation, suppression et vos choix

  • Données de l'appareil : les paramètres de l'extension et les métadonnées de téléchargement restent jusqu'à ce qu'ils soient remplacés, effacés ou que l'extension soit supprimée. Les instantanés d'aperçu du site Steam peuvent survivre à la suppression de l'extension ; effacez le stockage du site Steam séparément pour les supprimer (cela peut vous déconnecter). Les fichiers téléchargés doivent être supprimés par vous.
  • Compte du site et contenu enregistré : restent tant que cela est nécessaire pour votre compte et les services sélectionnés, jusqu'à ce qu'ils soient remplacés ou supprimés. Contactez l'assistance pour demander l'accès, la correction ou la suppression de votre compte, de l'instantané importé et des médias associés. Nous pourrions avoir besoin d’une vérification proportionnelle de la propriété ; ne fournissez jamais de mot de passe ou de jeton de session.
  • Résultats temporaires : Les liens de téléchargement du processus normal expirent après un intervalle configuré (24 heures par défaut) ; Les entrées de l’historique des profils AI sont configurées pour expirer après sept jours. Les autres tâches multimédias et objets R2 suivent leurs paramètres de nettoyage des tâches et de cycle de vie du compartiment. Un lien expirant ne signifie pas que toutes les copies seront immédiatement effacées.
  • Journaux, sauvegardes et fournisseurs : la rétention dépend de la rotation opérationnelle, de la sauvegarde et des politiques du fournisseur. Un délai de suppression vérifié unique pour toutes ces copies n’est pas actuellement publié. Les sauvegardes résiduelles ne sont pas des profils d'utilisateurs actifs ; les obligations légales ou de sécurité peuvent nécessiter une conservation limitée. Le support peut clarifier la conservation applicable pour une demande particulière.

Vous pouvez désactiver l'extension ou l'accès à son site, cesser d'utiliser les services d'importation/IA, effacer les données locales et utiliser les contrôles de modification/suppression disponibles. La désinstallation de l'extension ne supprime pas votre compte de site Web ou le contenu déjà téléchargé sur Steam. Les droits d'accès, de rectification, d'effacement, de restriction et d'opposition peuvent s'appliquer en vertu de votre législation locale ; vous pouvez également contacter votre autorité de protection des données.

08 Utilisation limitée, partage et sécurité

Notre utilisation des données obtenues via SteamShowcase Helper se limite à fournir ou à améliorer les fonctions indiquées pour l'utilisateur et suit la politique relative aux données utilisateur du Chrome Web Store, y compris ses exigences d'utilisation limitée. Nous ne vendons pas les données des utilisateurs d'extension, ne les utilisons pas à des fins de publicité personnalisée et ne les transférons pas à des fins de solvabilité ou de décisions de prêt. Nous n’envoyons pas de données d’extension pour une formation générale en IA sans rapport.

Les données sont partagées uniquement si nécessaire pour les fonctionnalités décrites ici, avec les prestataires de services nécessaires, pour des raisons de sécurité ou de conformité légale, ou dans le cadre d'un transfert d'entreprise autorisé avec notification/consentement légalement requis. L'accès humain aux données d'extension est limité à votre consentement spécifique (par exemple, assistance), aux enquêtes de sécurité nécessaires, à la conformité légale ou aux opérations internes agrégées/anonymisées, comme le permet la politique.

Les transferts de service public utilisent HTTPS. Les contrôles d'accès, les tickets d'importation limités et les origines d'intégration restreintes contribuent à protéger les données ; aucun système ne garantit une sécurité absolue. Les fournisseurs peuvent traiter des données en dehors de votre pays selon leurs conditions et garanties applicables. Cette politique ne prétend pas que chaque volume de stockage ou fournisseur est audité de manière indépendante.

Nous utilisons le traitement demandé pour fournir le service, le traitement opérationnel nécessaire pour le sécuriser, le consentement si requis pour le traitement facultatif et les obligations légales le cas échéant. Les modifications apportées à cette politique seront publiées ici avec une date mise à jour. Les nouvelles finalités nécessitant le consentement nécessiteront ce consentement avant utilisation.
