# SABA motion sources

`opensourceavatars.motionpack.json.gz` contains sampled humanoid bone curves
derived from the Mixamo FBX demonstrations published in the VRM Inspector:

https://github.com/ToxSam/osa-gallery/tree/main/public/animations

The original FBX containers, rigs and meshes are not distributed by this
project. The compact pack contains only retargetable rotation samples used by
the landing-page character. It deliberately retains only Bored and Looking.
The source repository describes its website code as MIT-licensed and identifies
the files as Mixamo animations. Adobe's Mixamo
FAQ permits royalty-free use of Mixamo characters and animations in personal,
commercial and non-profit projects:

https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html

`Goodbye.vrma` is the character's click-only reaction and comes from:

https://github.com/tk256ailab/vrm-viewer/tree/main/VRMA

It is distributed under the MIT license included in `LICENSE.txt` and is never
part of the automatic ambient animation cycle.
