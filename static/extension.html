02 / BEFORE YOU START

Install the extension once

  1. 01Open Chrome Web Store, click “Add to Chrome”, and confirm.
  2. 02Refresh your Showcase Maker tab after installation. You can pin the extension from Chrome’s puzzle icon.
  3. 03Sign in to Steam in the same browser. Then open Showcase Maker’s Steam tab.

03 / PREPARE FILES

First, prepare your finished files

After processing, Showcase Maker downloads a ZIP automatically. Unzip it: upload the numbered files, not the ZIP itself.

Select part_1, part_2 and so on in order. Do not upload auxiliary files such as full_original or preview. Each primary file must be 5 MB or less.

04 / ROUTE A

Automatic upload

Select the finished files in the extension’s full-page tab; it then guides the upload.

  1. 01On the website, open “Tools → Steam” and choose Workshop, Featured, or Split.
  2. 02Click “Open file picker”. A full-page SteamShowcase Helper tab will open.
  3. 03Add the extracted part_1, part_2… files in order. Check that the file count matches the showcase type.
  4. 04Leave “Auto upload” on and click “Upload”. Keep the tab open while it works, then check the showcase in Steam.
05 / ROUTE B

Manual upload with the extension

Use this route if you prefer to select each file on Steam yourself.

  1. 01Unzip the finished ZIP and keep the numbered files nearby.
  2. 02In “Tools → Steam”, choose the showcase type and click “Manual upload via extension”.
  3. 03The relevant Steam page opens. Select the files yourself, in order: part_1, then part_2, and so on.
  4. 04Review the preview and save your changes on Steam. The extension helps apply long-showcase settings.

06 / IF SOMETHING GOES WRONG

Common questions

The upload buttons are disabled

Check that the extension is installed and enabled, then refresh the Showcase Maker tab. A tab opened before installation may not detect it until refreshed.

The extension does not accept the files

Do not select the ZIP itself. Extract it and add the primary files in order. Each primary file must fit Steam’s 5 MB limit.

Steam did not open or the upload stopped

Make sure you are signed in to Steam in the same browser. Keep the extension tab open while uploading and retry. You can use the manual route instead.
