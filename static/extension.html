01

Everything in one window

Click the extension icon or press Ctrl+Shift+S. Automatic upload, presets, file processing on the website and the Steam page helpers all start here.

  • “Automatic upload” is the main route: pick the files, the extension does the rest
  • “Process” opens Showcase Maker if your files are not ready yet
  • Russian and English interface, switched with one button
02

Automatic upload: just drop the files

Choose the showcase type and the extension shows exactly as many slots as it needs. Drop the files into the slots or pick them with the button, then press Upload.

  • Five types: Artwork (2 files), Featured Artwork (1), Workshop (5), Screenshots (2), Guide (1)
  • Files of 5 MB or more are flagged before anything reaches Steam
  • The “Auto upload” switch presses Steam’s Save button for you

03

Upload queue: every file in sight

Steam opens in one background tab and the files go up one by one. The progress page shows which file is uploading and which are done.

  • Status and thumbnail for every file, overall progress and a Cancel button
  • If a file fails, the queue moves on and shows the error plainly
  • When done: Go to profile, Edit showcases and Place the uploaded files automatically

04 · new

“Pick automatically”, right inside Steam

Steam’s showcase editor gets a “Pick automatically” button on Artwork, Featured Artwork and Workshop showcases. It lists your recent uploads in batches and puts the batch you choose into the row you choose, in upload order.

  • No more hunting for five parts among a hundred old uploads
  • For the Workshop showcase you choose the row: 1, 2 or 3
  • Only the preview changes. Your profile updates when you press Save at the bottom
1 · Pick a batch and a row 2 · Showcase ready, press Save
05 · new

Upload batches in Steam’s file picker

When you pick a file for a showcase by hand, Steam’s window also shows your uploads in batches: date, number of files and each file’s place in the batch.

  • Sort newest or oldest first
  • “Show older” loads the next pages right in the window
  • A batch is one upload, so the parts never get mixed up
06 · new

My presets: a profile look in one click

A preset is a profile background plus your showcases with their files, in order. Keep a few and switch between them, for a season or an event.

  • “Save my current profile as a preset” captures what your profile shows now
  • “Apply in Steam”: the background goes on right away (full screen or original size), the showcases get arranged, you press Save
  • The previous background is kept and restored in one click; presets export and import as a file
07

Works together with the website

Showcase Maker detects the extension. After processing you can open the file picker or the manual upload straight away, with the showcase type already set.

  • The Steam tab in Tools shows that the extension is connected and its version
  • Profile import: the extension hands your Steam profile to the website’s profile editor
  • Files not ready yet? The Process button in the extension leads to the website

FAQ

Common questions

Is the extension free?

Yes. The extension is free; it has no subscription of its own.

The upload buttons on the website are disabled

Check that the extension is installed and enabled, then refresh the Showcase Maker tab. A tab opened before the installation will not see it until refreshed.

The extension does not accept the files

Do not pick the ZIP itself: unzip it and add the primary files part_1, part_2… Each must be under 5 MB.

There is no “Pick automatically” button in Steam

Reload the showcase editor. The button appears on Artwork, Featured Artwork and Workshop showcases, so pick one of these types.

A batch is missing files

Upload the parts of a showcase in one go so they land in one batch. If part of a batch is on the next page, press “Show older”.

Steam did not open or the upload stopped

Check that you are signed in to Steam in the same browser and keep the upload page open while the queue runs. Retry, or upload by hand with the Steam helpers.
