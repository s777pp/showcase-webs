# Built-in Builder effects

The four RGBA textures in this directory are original Showcase Maker assets
generated for this project with OpenAI image generation on 2026-09-12. The
second pass uses a fine-particle scale: many small isolated elements with ample
transparent space instead of a few oversized foreground objects. They are
stored locally so Builder previews and exports do not depend on a third-party
stock CDN or redistribute stock-library downloads.

The browser applies motion, looping, colour tint, density, scale, rotation and
opacity at render time. Source textures must remain PNG with an alpha channel.
