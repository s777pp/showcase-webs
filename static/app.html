How to use
  1. Background — image the character is placed on (PNG/JPG).
  2. Character — transparent PNG, or photo/video on green, blue or red screen.
  3. Live preview on the right. Drag the character, use the corner handle or mouse wheel to resize. Sliders work too.
  4. Colored backdrop — leave auto remove. Pre-cut PNG — choose already transparent.
  5. Tolerance — chromakey strength. Smoothing — edge softness (0 = hard).
  6. Press Compose → download or send To Process for Workshop slicing.
