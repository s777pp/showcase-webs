Загрузка товаров в магазин Ko-fi

Расширение по очереди создаёт товары в твоём аккаунте Ko-fi: заполняет поля, выбирает категории, загружает превью и файл для покупателей и сохраняет. Сначала войди на ko-fi.com в этом браузере. Не закрывай эту вкладку, пока идёт загрузка.

1 · Файлы для продажи

Каждый файл (ZIP, RAR, PNG…) — отдельный товар. Название берётся из имени файла, его можно поменять. Превью — картинка, которую видят покупатели: выбери для строки или подбери сразу все по имени файла.

2 · Одинаково для всех товаров

В текстах можно писать {name} — имя из строки выше и {title} — готовое название товара. Эти настройки запоминаются.
